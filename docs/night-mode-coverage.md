# 夜间模式回归范围

覆盖小鹅通电脑版商家页面的常用入口和共用组件。回归使用加载真实扩展的独立 Chromium，拦截测试站点请求，用按原站组件结构编写的夹具模拟空态、有内容、等待加载和前端切页；测试不登录真实账号、不发布评论、不提交练习或付款。

| 入口 | 回归重点 |
| --- | --- |
| 店铺首页、导航搜索、我的已购、学习记录 | 导航与展开的搜索框、商品/记录卡片、进度、店标、分页控件 |
| 课程主页、专栏、会员课、视频、音频、图文、文档 | 简介、播放器外围、详情与目录标签、目录展开、店铺卡片、受支持的视频及封面 |
| 课程页与商品详情页的评论及互动 | 空态、评论输入与焦点、禁用发布、已有评论和引用、确认层、互动项目与入口 |
| 资料及登录弹窗、无权限与不支持页面 | 标题、文件名、链接、提示条、操作按钮；二维码和课件内容保留原样 |
| 练习历史、错题、收藏、答题、结果及解析 | 主要面板、答题卡、选项和结果、加载层、嵌入视频，及跨页面还原 |
| 直播/回放与共用加载 | 支持的播放器亮度、整页和局部加载遮罩、加载动画原色在浅色模式下还原 |

测试入口：`output/playwright/verify-site-appearance.js`。新增原站组件时优先按组件类适配，并补充浅色恢复及空态回归。

边界：课程作者自定义富文本样式、外部表单、支付和第三方 iframe 不在此覆盖清单内。媒体原件、图片、PDF、原始帧截图和系统强制颜色模式不做全页滤镜处理。需要权限且没有可访问样本的状态仅验证对应组件，无真实账号端到端结论。
