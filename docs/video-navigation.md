# 同课程视频局部切换

## 范围与实现

- 支持 `/p/t_pc/course_pc_detail/video/<视频 ID>?product_id=<课程 ID>` 页面的同课程视频目录。通过原组件的目录方法接入，保留网站的权限、解锁和信息收集检查；跨课程、直播、其他资源类型和带修饰键的点击仍走原网站入口。
- 使用原 Vue Router 更新地址与浏览历史，复用网站的课程读取、商品信息、信息收集与权限查询。不是仅替换媒体 URL，视频信息、播放器及学习上报 ID 一起更新。
- 先暂停、收尾并销毁旧播放器，再加载新视频。仍渲染网站的 ContentHeader 和 BasicVideoPlayer／OldVideoPlayer，不创建替代控件；画质、快捷键等扩展功能继续识别新的播放器。
- 保留目录实例、章节展开状态及滚动位置；按资源重新创建详情、评论、互动与课件等内容，防止组件缓存继续显示上一节信息。新视频标题使用网站返回的标题。
- 连续点选时串行完成原生数据读取，只初始化最后排队的视频；前进、后退也走相同生命周期。读取超时、资源 ID 不符或需要网站通用权限页时退回普通整页打开，防止把旧数据用于新视频。
- 不修改全网站的导航，不影响从课程主页首次进入播放器。组件不匹配或尚未就绪时不接管。网站升级后可能需要重新适配。
- 不新增权限、持久化缓存或外部数据服务；停用网站功能后还原目录方法与渲染处理。正在切换时停用，会正常重新打开当前目标页面，避免遗留半初始化界面。

## 验证

2026-10-24 在已登录的实际课程页面完成同课程切换与历史返回：document 和目录实例不变，展开状态保留，播放器、视频数据、地址及标题对应同一资源。测试结束恢复原视频、暂停状态与时间位置。实际商家播放器在测试中短暂绕过通用播放拦截，随后已暂停；不将此过程表述为全程无播放。

`tests/video-navigation-smoke.js` 验证网站授权、启停、顶层 frame、路由及 document ID 限制。

`output/playwright/verify-video-navigation.js` 在全新 MV3 扩展配置下使用真实 Vue 2.7／Vue Router 3 和隔离接口，分别覆盖两种播放器的目录 DOM 身份、滚动位置、详情／评论／课件、原有控件、旧 SDK 销毁、学习上报 ID、前进后退、连续点选、权限／跨课程／修饰键、事件监听清理、停用恢复和读取异常回退。夹具不访问个人学习数据，不提交真实学习记录；播放器 SDK 为测试替身，真实商家 SDK 另经上述页面验证。
