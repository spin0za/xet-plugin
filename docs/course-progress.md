# 课程目录静默更新

2026-10-22 核实接口；2026-11-10 核对当前桌面课程程序的全部路由、目录类型、实际可见性监听器和学习完成事件。插件只调用读取接口，不修改学习记录；网站自身的学习上报保持原样。

## 字段来源

| 查询 | 核实返回的字段 | 用途 |
| --- | --- | --- |
| `xe.course.business.e_course.learning_resource_progress.get/1.0.0` | `progress`、`include_elective` | 课程总进度；后者表示选修计入设置，不是逐节数据 |
| `xe.course.business_go.avoidlogin.e_course.resource_catalog_list.get/1.0.0` | `list[].chapter_id`、`p_id`、`study_status`、`learn_progress`、`unlock_state`、`unlock_date` 等目录字段 | 按条目 ID 更新完成状态、已学百分比和解锁状态 |
| `xe.course.business_go.e_course.last_learn_resource.get/1.0.0` | `resource_id`、`resource_type`、`jump_url`、`last_learn_course_name`、`sub_course_id` | 更新目录中的上次学习标识；原网站的继续学习按钮仍执行原有独立查询 |

目录查询通过当前 Vue 组件的 `apiMap.getList` 复用网站的参数和请求处理；上次学习通过 `apiMap.getLearnResource` 读取。未将完整目录响应、用户信息或登录凭据写入存储。

## 行为范围

- 对课程主页、视频、音频、文档、图文及其他课程详情入口，先识别实际的 `CourseContentCatalog` / `CampProCatalog`，再验证所属课程。支持 `product_id`、`pro_id`、`parent_pro_id`、`course_` / `c_` 标识及无查询参数但原组件提供所属课程的入口；参数、组件和课程冲突时不猜测接管。
- 专栏、大专栏、会员、训练营使用其他目录组件时不接管，也不发送课程进度查询；无权限页、课程选择中间页、直播、练习和 H5 独立程序不在本适配器范围。社群专用 API 环境尚未核实，不套用普通课程接口。
- 当前 `ContentCatalog.created` 注册同步的可见性回调，并提供一个延后一任务调用的备用方法。两者均受保护；不把仅存在的方法误认为当前实际注册的监听器。
- 捕获切回事件期间，把原生目录的 `reload()` 调用替换为数据读取。其他 `visibilitychange` 监听器照常运行，手动触发的原生重载仍执行原方法。
- 只查询已加载的根目录页和已加载章节的子页，包括已折叠但仍保留数据的章节；不扫描未加载目录，也不新增标签页。
- 修改原有响应式对象的状态字段，不替换条目、数组、展开状态、分页或滚动位置。不会自动打开上次学习的章节或把视图滚回该条目。
- 文档／图文完成学习、音频／视频进度触发的原生 `catalogRefresh` 事件，通过 `reloadSwitch` 的专用 Vue 用户监听器改为静默读取；兼容 Vue 2.6 / 2.7 的监听器存放位置。没有替换全局事件总线，没有改动上报、播放器、文档 iframe、其他监听器或原生定时器。无法识别专用监听器时不修改它。
- 搜索期间保留结果，学习进度变更暂记为待更新，结束搜索后立即处理；不把搜索结果重置为根目录。
- 并发不超过四个请求；重复切回合并在途读取，学习完成事件若晚于当前读取开始，则补一次读取，避免漏掉最新进度。查询失败保留已有数据，不自动重建目录。仅存在课程总进度组件时查询总进度。
- 子课程、排序、权限筛选、组件或数组改变后忽略对应旧结果。停用网站功能时恢复原方法并撤销监听器。
- 同课程视频局部切换复用现有保护，不等待下一次轮询才生效；后台按授权来源和具体文档限制注入，MAIN 再核对当前路径及课程 ID，不依赖可能保留初始地址的消息发送方路径。
- 手动重载、搜索、排序、子课程切换、筛选及主动解锁的方法不被替换。账号、权限或信息收集状态改变后先让原生刷新重新核对，轮询不会直接把新权限状态当成可安全静默更新的状态。服务器目录响应的可访问／订阅状态改变时也交回原生目录校验，不重载阅读内容。
- 目录原生重建时撤销旧实例的监听，并通知内容脚本及时接管替代实例，不等待五秒身份轮询；其他内容及文档／媒体节点不被重建。
- 新增／删除章节、标题或目录结构不靠进度字段推断；原生结构变更／解锁流程、重新进入页面和手动刷新仍可取得完整目录。

## 检查

`tests/course-progress-smoke.js` 验证入口、组件类型、授权、当前地址和具体文档限制。`output/playwright/verify-course-progress.js` 对课程主页、视频、音频、文档和图文运行真实 MV3 夹具，覆盖同步／延后切回、在途合并、DOM／数组身份、展开及滚动、失败和过时结果、停用恢复与 SPA 离开。

`verify-course-progress-events.js` 另以真实 Vue 2.6 / 2.7、原生属性监听器和事件总线验证异步完成上报、事件传播、文档预览 iframe 与媒体节点不重建、搜索保留及结束后更新、在途完成补读、客户端及服务器权限变化回退、目录重建后及时接管、监听器恢复，以及各类非课程目录和社群专用 API 环境不被接管。文档预览使用可滚动 iframe 夹具，不冒充实际第三方 PDF 阅读器实测。

`verify-video-navigation.js` 使用真实 Vue 2 / Vue Router 同时运行静默更新及视频切换。无头浏览器不会随标签切换改变可见性，因此夹具显式派发事件；真实网站的接口与字段另经已登录页面核实。
