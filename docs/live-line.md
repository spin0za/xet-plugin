# 默认直播线路

2026-11-15 在已登录直播回放中核实：`.pc-live-player` 内的 `.line-switch-btn` 持有线路菜单，`.line-switch-menu .menu-item.selecter-item` 分别显示“线路1／线路2／线路3”，当前项使用 `.active`。同一菜单也包含分辨率选项，不能把“原画”等当成线路。原组件的 `changeLine(index)` 只在索引不同时向播放器发出 `changeLine` 事件；插件通过对应原生选项的点击处理复用该流程，不改写媒体地址或播放器参数。

## 设置与范围

- 弹窗提供原生 `select`，保持现有卡片样式、标签、说明和键盘焦点；保存失败回滚，与画质／音量／保活开关相互独立。
- `chrome.storage.local.defaultLiveLine`：0 跟随网站（初始默认），1／2／3 为首选线路。非法值按跟随网站处理；已有用户其他设置保持不变。不新增权限，不使用同步存储。
- 仅匹配 `/p/t_pc/live_pc/pc/l_…` 下的原生直播播放器，直播与直播回放共用。普通课程视频、解析嵌入视频、直播介绍页不选线。
- 精确匹配线路文字和可用状态；菜单初始隐藏也可使用网站已挂载的点击处理。目标不存在或禁用时不猜选其他线路，等待可用菜单挂载。
- 每个当前房间／偏好只初始化一次，已选中则不点击。原生切换一经发起即结束接管，后续 SDK 重建、断线恢复、网站故障切线均不强制改回。真实鼠标／键盘选线的捕获处理先于待执行的默认操作，手动选择优先；插件合成点击不冒充手动意图。
- 更换房间或显式变更偏好可重新初始化；站点停用取消待执行操作并移除监听，重新启用仍保留当前房间的已处理／手动意图。不改变时间、倍速、音量、播放／暂停、画质或菜单外观；原生切线所需的正常媒体重连仍由网站处理。
- 菜单迟到时用变更观察发现；不因每条聊天消息重扫播放器。初始化结束或跟随网站时移除观察器。轻量路由检查只比较路径／设置，不发送查询。

## 验证

`tests/live-line-smoke.js` 覆盖默认／非法值、精确选项、已选中、缺失／禁用／迟到菜单、手动意图竞态、自动故障切线、设置／路径变化与清理。`tests/frame-policy-smoke.js` 验证网站停用继续停止此功能；`tests/popup-smoke.js` 检查设置标签和选项。

`output/playwright/verify-live-line.js` 在独立真实 MV3 扩展中验证隐藏菜单、一次原生点击、手动线路 3、故障切回、已选中／迟到线路、网站停用、跟随网站、设置变更、普通课程排除，以及真实扩展弹窗的保存／重新加载／传播、键盘焦点和尺寸。模拟播放器不请求真实媒体；未在用户的播放中强行测试切线。

本次仅将用户现有扩展的 `defaultLiveLine` 写为 2 并回读确认，其他存储不变。当前用户播放器已选线路 2，保持播放及 1.25 倍速，没有刷新或重新切线。重新加载新版本扩展后，后续新进入的直播／回放会应用该偏好。
